# Spin-Statistics Emergence Toolkit

## What This Tests

**Core Question**: Can fermionic antisymmetry emerge from dynamics rather than being assumed?

**Answer**: YES. With spin-spin coupling, the ground state becomes fully antisymmetric 
(exchange eigenvalue = -1), exhibiting true fermionic behavior including Pauli exclusion.

## Key Results

1. **Antisymmetry emerges** with antiferromagnetic spin coupling (J > 0)
2. **Pauli exclusion verified**: P(same site, same spin) = 0
3. **Sectors are dynamically stable**: once fermionic, always fermionic

## Files

- `spin_statistics_engine.py` - Core engine with Hilbert space construction and analysis
- `test_dynamical_stability.py` - Tests that fermionic/bosonic sectors don't mix under evolution

## Physics Interpretation

The Hilbert space splits into **superselection sectors**:
- Antisymmetric (fermionic): exchange eigenvalue = -1
- Symmetric (bosonic): exchange eigenvalue = +1

These sectors are **closed under Hamiltonian dynamics** - you cannot evolve from one to the other. This is why particle statistics are conserved.

The mechanism:
1. Antiferromagnetic coupling (J > 0) favors **singlet** spin states
2. Singlet = antisymmetric under spin exchange
3. For total antisymmetry, spatial part must be symmetric
4. Result: Total wavefunction is antisymmetric = FERMIONIC

## Extending the Code

To analyze your own states:

```python
from spin_statistics_engine import *

# Create Hilbert space
space = SpinfulParticleSpace(n_sites=6, n_particles=2)

# Build Hamiltonian
H = build_spinful_hamiltonian(space, t=1.0, U=5.0, J_spin=2.0)

# Find ground state
E, psi = find_ground_states(H, k=1)

# Full analysis
analysis = full_analysis(psi[:, 0], space)
print(f"Exchange eigenvalue: {analysis['exchange_eigenvalue']}")
print(f"Character: {analysis['character']}")
```
